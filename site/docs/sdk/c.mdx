The three packages are wrappers over this. Include the header, link the
library, and you have everything they have.

## The shape of every call

- Inputs are a pointer and a length. `NULL` with zero means absent.
- Byte outputs are `GvBuffer` cells the library fills. Free each one once with
  `gv_free`.
- Every call returns a `GvStatus`. Zero is success, and on any other status
  every output cell is left empty.
- Records go in and out as bytes. There are no handles to keep.

```c
#include <gossveil.h>

typedef struct GvBuffer {
    uint8_t *ptr;
    size_t len;
} GvBuffer;
```

## Starting up

```c
if (gv_abi_version() != GV_ABI_VERSION) return 1;
```

For a host that cannot hand the library its own memory, such as wasm:

```c
uint8_t *input = gv_alloc(len);
gv_free(input, len);
```

## Keys

```c
GvBuffer secret = {0}, public_key = {0};
if (gv_curve_pair(&secret, &public_key) != GV_OK) return 1;

gv_curve_public(secret.ptr, secret.len, &public_key);
gv_curve_sign(secret.ptr, secret.len, message, message_len, &signature);
gv_curve_verify(public_key.ptr, public_key.len, message, message_len, sig, sig_len);
gv_curve_agree(secret.ptr, secret.len, theirs, theirs_len, &shared);
gv_curve_check(public_key.ptr, public_key.len);

gv_pq_pair(&pq_secret, &pq_public);
gv_pq_encapsulate(pq_public.ptr, pq_public.len, &ciphertext, &shared);
gv_pq_open(pq_secret.ptr, pq_secret.len, ciphertext, ciphertext_len, &shared);

gv_identity_pair(&identity);
gv_identity_serialize(identity.ptr, identity.len, &bytes);
gv_identity_parse(bytes, bytes_len, &identity);
gv_identity_vouch(ours, ours_len, theirs, theirs_len, &proof);
gv_identity_vouched(ours, ours_len, theirs, theirs_len, proof, proof_len);

gv_free(secret.ptr, secret.len);
```

A session record goes in and a new one comes out. Persist the one that comes
out before you send anything, or a crash loses a ratchet step.

## Statuses

```c
typedef enum GvStatus {
    GV_OK = 0,
    GV_BAD_ARGUMENT = 1,
    GV_BAD_STATE = 2,
    GV_BAD_KEY = 3,
    GV_BAD_SIGNATURE = 4,
    GV_BAD_MESSAGE = 5,
    GV_UNKNOWN_KEY_ID = 6,
    GV_UNTRUSTED_IDENTITY = 7,
    GV_NO_SESSION = 8,
    GV_REPLAY = 9,
    GV_LEGACY_VERSION = 10,
    GV_UNKNOWN_VERSION = 11,
    GV_OUT_OF_MEMORY = 12,
    GV_VERIFY_FAILED = 13,
    GV_INTERNAL = 14

```

A human-readable form, for logs:

```c
const char *text = gv_status_text(status);
```

## Message kinds

The first byte a client puts on the wire:

```c
#define GV_KIND_WHISPER 2u
#define GV_KIND_FIRST 3u
#define GV_KIND_CIRCLE 7u
#define GV_KIND_PLAIN 8u
```

Post-quantum parameter sets, as the tag byte on a serialized key:

```c
#define GV_PQ_ROUND_THREE 0x08u
#define GV_PQ_STANDARD 0x0Au
```

## Freeing

Free every `GvBuffer` exactly once with `gv_free`, passing the same pointer and
length the library gave you. Anything your own allocator made is yours to
free the usual way.

See [writing your own SDK](/docs/binding/writing-an-sdk) if you're wrapping
this for another language.
